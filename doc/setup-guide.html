🚀 Vite + shadcn/ui 구축 가이드 (Full Version)

1. 프로젝트 초기화

# 1. 프로젝트 생성
npm create vite@latest dividend-manager -- --template react-swc-ts

# 2. 필수 라이브러리 설치
cd dividend-manager
npm install
npm install -D tailwindcss@3 postcss autoprefixer @types/node
npm install clsx tailwind-merge class-variance-authority lucide-react @radix-ui/react-slot
npx tailwindcss init -p

2. 환경 설정 파일 (4개 핵심 설정)

① components.json (프로젝트 루트) (직접생성해야 함)

{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "default",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "src/index.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"
  }
}

② tsconfig.app.json (에디터 경로 인식)

compilerOptions 안에 baseUrl과 paths를 추가합니다.

{
  "compilerOptions": {
    "composite": true,
    "target": "ESNext",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    },
    // ... 나머지 설정
  }
}

③ vite.config.ts (Vite 빌드 경로 설정)

import path from "path"
import react from "@vitejs/plugin-react-swc"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { "@": path.resolve(__dirname, "./src") },
  },
})

④ tailwind.config.js (CSS 감시 경로)

/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: { extend: {} },
  plugins: [],
}

3. 컴포넌트 설치 및 수동 이동

⚠️ 윈도우 환경 필독: npx 명령 실행 후 루트에 @ 폴더가 생기면, @/components/ui 안의 파일들을 src/components/ui로 직접 옮기고 @ 폴더는 삭제하세요. 
npx shadcn@latest add button input card label

4. 실제 코드 작성 (UI & Logic)

1) src/lib/utils.ts (유틸리티)

import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}

2) src/index.css (최상단 확인)

@tailwind base;
@tailwind components;
@tailwind utilities;

3) src/pages/LoginPage.tsx (로그인 화면)

import React, { useState } from "react";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@/components/ui/card";

export default function LoginPage() {
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");

  const handleLogin = (e: React.FormEvent) => {
    e.preventDefault();
    alert(`로그인 시도: ${email}`);
  };

  return (
    <div className="flex items-center justify-center min-h-screen bg-slate-50 p-4">
      <Card className="w-full max-w-md shadow-lg">
        <CardHeader>
          <CardTitle className="text-2xl font-bold text-center">로그인</CardTitle>
          <CardDescription className="text-center">서비스 접속을 위해 정보를 입력하세요.</CardDescription>
        </CardHeader>
        <form onSubmit={handleLogin}>
          <CardContent className="grid gap-4">
            <div className="grid gap-2">
              <Label htmlFor="email">이메일</Label>
              <Input id="email" type="email" value={email} onChange={(e) => setEmail(e.target.value)} required />
            </div>
            <div className="grid gap-2">
              <Label htmlFor="password">비밀번호</Label>
              <Input id="password" type="password" value={password} onChange={(e) => setPassword(e.target.value)} required />
            </div>
          </CardContent>
          <CardFooter>
            <Button type="submit" className="w-full bg-blue-600">로그인</Button>
          </CardFooter>
        </form>
      </Card>
    </div>
  );
}

5. 메인 연결 (App.tsx & main.tsx)

① src/App.tsx (페이지 조립)

기본 Vite 샘플 코드를 모두 지우고, 작성한 LoginPage를 불러옵니다.

import LoginPage from "@/pages/LoginPage";

function App() {
  return (
    <div className="App">
      <LoginPage />
    </div>
  );
}

export default App;

② src/main.tsx (엔트리 포인트)

index.css가 반드시 임포트되어 있어야 스타일이 적용됩니다.

import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.tsx'
import './index.css' // 스타일 적용의 핵심!

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
